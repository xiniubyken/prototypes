# PRD — 省外跨区审批增加登录时间

> 需求池：6月需求书 | 交付日期：2026-05-19 | 模块：工程管理→省外跨区审批

---

## 1. 需求背景

审批人员处理跨区申请时需要工程单登录时间来判断优先级和时效性，当前列表页和详情页均缺少该信息。

**核心改动**：筛选栏、列表页、详情页新增【登录时间】字段。

---

## 2. 改动范围

| 页面 | 改动 |
|------|------|
| 省外跨区审批 — 列表页 | 筛选栏+列表列新增登录时间 |
| 申请跨区审批/查看 — 详情页 | 基本信息新增登录时间 |
| 二次申请跨区审批/查看 — 详情页 | 同上 |

不受影响：转单审批、修改项目信息、增加安装地址

---

## 3. 列表页

### 筛选栏

| 字段 | 类型 | 位置 | 规则 |
|------|------|------|------|
| 登录时间(NEW) | 日期范围（起始~结束） | 工程单号后 | 默认空=全部；格式YYYY-MM-DD |

字段顺序：工程单号 → **登录时间(NEW)** → 跨区单号 → 经销商名称 → 安装地址 → 创建时间 → 审批状态 → 显示过滤 → 跨区销司 → 被跨区销司 → 审核等待时间 → 查询/重置

### 列表列

| 列名 | 数据来源 | 位置 | 格式 |
|------|----------|------|------|
| 登录时间(NEW) | 工程单→基本信息→登录时间 | 工程单号后 | YYYY-MM-DD，只读 |

列顺序：操作 → 工程单号 → **登录时间(NEW)** → 跨区单号 → 跨区销售公司 → 被跨区销售公司 → 经销商名称 → 申请原因 → 状态 → 审核等待时间 → 申请时间

---

## 4. 详情页

4个详情页（申请跨区审批/查看、二次申请跨区审批/查看）改动一致：

### 基本信息新增

| 字段 | 数据来源 | 位置 | 规则 |
|------|----------|------|------|
| 登录时间(NEW) | 工程单→基本信息→登录时间 | 工程单号后 | 只读，YYYY-MM-DD |

字段顺序：工程单号 → **登录时间(NEW)** → 跨区销售公司 → 跨区销售公司联系人 → 跨区销售公司联系电话 → 经销商名称 → 被跨区销售公司 → 跨区编号 → 跨区结果

---

## 5. 数据规格

| 字段 | 类型 | 必填 | 默认 | 来源 |
|------|------|------|------|------|
| 登录时间（筛选） | Date Range | 否 | 空 | 用户输入 |
| 登录时间（列表/详情） | Date YYYY-MM-DD | - | - | 工程单基本信息自动带出 |

---

## 6. 验收标准

1. 筛选栏登录时间日期范围筛选可用，默认空=全部数据
2. 列表登录时间列位于工程单号后，格式YYYY-MM-DD
3. 4个详情页基本信息登录时间位于工程单号后，只读
4. 数据来源：关联工程单→基本信息→登录时间
5. 其他子页签不受影响

---

## 7. 任务拆解

### 任务总览

| # | 任务 | 类型 | 页面 | 优先级 | 预估 |
|---|------|------|------|--------|------|

| T3 | 详情页基本信息新增登录时间 | 前端+接口 | 4个详情页 | P0 | 0.5h |

**总预估：3.5h**

### T1 — 筛选栏新增登录时间筛选

**前端改动**：

| 项目 | 说明 |
|------|------|
| 位置 | 筛选栏第2位，工程单号后 |
| 类型 | 日期范围选择器（起始~结束） |
| 默认值 | 空=全部数据 |
| 格式 | YYYY-MM-DD |
| 字段名 | loginTimeStart / loginTimeEnd |

**接口改动**：

| 项目 | 说明 |
|------|------|
| 接口 | 跨区审批列表查询接口 |
| 新增参数 | loginTimeStart（String, YYYY-MM-DD） |
| 新增参数 | loginTimeEnd（String, YYYY-MM-DD） |
| 筛选逻辑 | loginTimeStart ≤ 登录时间 ≤ loginTimeEnd；参数为空时不筛选 |

**UI Kit参数**：组件=日期范围选择器，输入框高M=28px，圆角2px，字号H4=13px，边框色#D7D7DB，填充色#F7F7F7，Grid位置=筛选栏5列Grid第2列

**验收点**：1.筛选栏登录时间在工程单号后 2.默认空=全部 3.选定范围后列表只显示对应时间段 4.重置清空

### T2 — 列表列新增登录时间

**前端改动**：位置=列表第2列（工程单号后），数据来源=接口loginTime，格式YYYY-MM-DD只读，列宽120px

**接口改动**：跨区审批列表查询接口新增返回loginTime（String, YYYY-MM-DD），来源=工程单基本信息

**UI Kit参数**：表头高32px，行高28px，字号H4=13px，NEW标记色#D32F2F，NEW标记th-bg#FFEBEE

**验收点**：1.列在工程单号后 2.格式YYYY-MM-DD只读 3.数据=工程单基本信息 4.列头有NEW标记

### T3 — 详情页基本信息新增登录时间

**前端改动**：适用4个详情页（申请跨区审批/查看、二次申请跨区审批/查看），位置=基本信息section工程单号后，格式YYYY-MM-DD只读

**接口改动**：跨区审批详情查询接口新增返回loginTime（String, YYYY-MM-DD）

**UI Kit参数**：标题固定宽60px，字号H4=13px，NEW标记色#D32F2F

**验收点**：1.4个详情页登录时间在工程单号后 2.只读YYYY-MM-DD 3.数据来源=工程单基本信息 4.NEW标记红色 5.其他子页签不受影响

### T4 — 接口返回登录时间字段

**后端改动**：

| 接口 | 新增字段 | 来源 | 说明 |
|------|----------|------|------|
| 跨区审批列表查询 | loginTime | 工程单.登录时间 | 列表展示+筛选 |
| 跨区审批详情查询 | loginTime | 工程单.登录时间 | 详情展示 |
| 跨区审批列表筛选 | loginTimeStart/loginTimeEnd | 用户输入 | 日期范围筛选参数 |

**数据映射**：跨区审批单→关联工程单→基本信息→登录时间。登录时间已存在于工程单基本信息中，无需新增字段，接口JOIN工程单表返回即可。

**验收点**：1.列表接口返回loginTime（YYYY-MM-DD格式） 2.详情接口返回loginTime 3.筛选参数正确过滤
