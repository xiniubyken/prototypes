# PRD — 大客户业务单卸货方式新增"不卸货不上楼"选项

## 一、背景与目标

### 1.1 背景
大客户业务单（直销工程客户、渠道工程客户、渠道工程备货）的卸货方式原有2个选项：卸货上楼、仅卸货不上楼。部分场景（如项目无电梯、楼层较高）经销商/管理端需要"不卸货不上楼"选项，当前系统无法选择，导致业务处理受限。

### 1.2 目标
卸货方式枚举值从2选项→3选项，新增"不卸货不上楼"。改动范围：经销商端3类型PC页面、管理端代客3类型PC页面、批量导入模板及校验规则。

---

## 二、改动概述

| 改动点 | 改动前 | 改动后 |
|--------|--------|--------|
| 卸货方式选项 | 卸货上楼、仅卸货不上楼（2选项） | 卸货上楼、仅卸货不上楼、不卸货不上楼（3选项） |
| 批量导入卸货方式枚举 | 2选项 | 3选项（新增不卸货不上楼） |
| 联动规则 | 配送=配送→卸货必填；配送=自提→卸货隐藏 | **不变** |

## 四、功能详细描述

### 4.1 使用方信息 — 卸货方式radio新增选项

**改动内容**：卸货方式radio组件从2选项→3选项，新增"不卸货不上楼"。

**联动规则（不变）**：
- 配送方式=配送 → 卸货方式必填且显示（3选项任选1）
- 配送方式=自提 → 卸货方式隐藏，非必填（填写也不写入数据）

**数据规范**：

| 字段 | 数据类型 | 长度 | 必填 | 默认值 | 校验规则 |
|------|---------|------|------|--------|---------|
| 卸货方式 | String | ≤20字符 | 条件必填 | 无 | 配送时必填，枚举值：卸货上楼/仅卸货不上楼/不卸货不上楼；自提时不校验 |

**使用方信息字段排列（两端一致）**：

| 序号 | 经销商端 | 管理端 | 差异说明 |
|------|---------|--------|---------|
| 1 | *采购单位 | *采购单位 | ✅ 一致 |
| 2 | *使用方负责人 | *使用方负责人 | ✅ 一致 |
| 3 | *联系方式 | *联系方式 | ✅ 一致 |
| 4 | *使用单位（仅渠道客户） | *使用单位（仅渠道客户） | ✅ 仅渠道工程客户有 |
| 5 | *配送方式 | *配送方式 | ✅ 一致 |
| 6 | *卸货方式 NEW | *卸货方式 NEW | ✅ 新增第3选项 |
| 7 | *安装地址 | *安装地址 | ✅ 一致 |
| 8 | *智能地址填写 | - | 经销商端独有 |
| - | - | 基本信息6字段section | 管理端独有 |
| - | 关联工程单+关联大盘 | - | 经销商端独有 |

**联系方式+使用单位布局**：
- 渠道工程客户：联系方式+使用单位同一行并排（half+half）
- 直销工程客户/渠道工程备货：联系方式自适应占满一行（无使用单位字段）

## 五、边界条件

| 边界场景 | 处理方式 |
|---------|---------|
| 配送方式=配送，卸货方式未选 | 提交校验拦截，提示"请选择卸货方式" |
| 配送方式=自提，卸货方式选了值 | 不写入数据，前端隐藏卸货方式radio |
| 批量导入配送方式=自提，卸货方式列有值 | 不写入数据，导入成功但不存储卸货方式 |
| 批量导入配送方式=配送，卸货方式为空 | 导入失败，提示"配送方式为配送时缺少卸货方式" |
| 渠道工程客户未填使用单位 | 提交校验拦截（使用单位仅渠道客户必填） |
| 直销/备货填了使用单位 | 不写入数据（前端无该字段） |
