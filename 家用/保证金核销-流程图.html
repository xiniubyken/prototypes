业务发起 · 流程要点

  • 存在审批中单时不允许发起新建；全部完结/驳回后恢复。
  • 提交时生成单据并进入审批；有返还生成 FH单，有收差生成 SC单。
  • 无返还不生成 FH单；无收差不生成 SC单；单价 0 SKU 不参与核销。
  • 同一订单行可分批核销；每批生成独立 BHX单/FH单/SC单 与行号，已提交数量从剩余可核销数量扣除。
  • 金额=数量×单价；需核销总数不含单价 0 SKU。

网批 · 审批规则

  • 审批中不可修改，提交什么审批什么。
  • 总部业务组长、总部业务主管：通过 / 驳回，驳回原因必填。
  • 销司确认：仅通过，无驳回按钮；7 天未审批由定时任务自动通过。
  • 销司确认后推送 FMS；网批显示“已提交 FMS”，等待 FMS 回传，责任归属 FMS。

驳回终态

任一节点驳回 → 核销单终态 → FH单/SC单 作废 → 复制并新建
  • 驳回后审批中数量释放回剩余可核销数量；原单保持已驳回。
  • 复制并新建跳转新建页带 copy 参数，原单信息预填，订单数据重算。
大白话：网批推给 FMS 等审批；FMS 通过后自己返还和收差，再分多段把结果回传；驳回就整单终态。

关键边界

  • FMS 不回传就一直等待；“已提交 FMS”状态责任归属 FMS。
  • FMS 驳回：回传网批后整单终态；SC单/FH单作废；可复制并新建。
  • 发票单号按收差单行号异步回推；回推前显示“回推中”。
  • 收差状态：待执行 → 执行中 → 已收差。
大白话：这是网批系统的汇总页。FMS 把审批和执行结果回传给网批，由网批更新页面数据。

FMS 对整张核销单只给一个结论：通过或驳回，不存在按合格/不合格拆分审批。整单通过后，合格数量随返还完成先回写，不合格数量等收差完成后再回写。剩余可核销：提交前 15 → 提交后 6 → FMS通过后 6 → 收差完成后 6。已返还/已收差金额为本单新增额，页面累计 = 历史值 + 本单新增。

回写规则

  • FMS 整单通过后：合格数量移出审批中数量并计入累计合格；不合格数量保留在审批中数量，待收差完成后再移出并计入累计收差。
  • FMS 回传结果 → 网批系统更新汇总页；不是 FMS 直接改网批页面。
  • 发票单号允许按 SC单行号批量回推网批。
  • 剩余可核销 = 追溯下单数量 − 历史累计合格 − 历史累计收差 − 审批中数量。
  • 方案待核销总数 = 需核销总数 − 已核销总数（含审批中）。

5幂等、事务与并发
以下为建议实现方案，实际事务、锁和幂等机制以开发实现为准。
两段回写幂等
第一段/第二段必须支持重复回传；同一段重复到达时直接忽略，不能重复加数
事务边界
审批中数量、累计合格、累计收差、已返还/已收差金额必须同一事务提交
并发回传
返还结果与收差结果同时到达时，按段次串行处理，先第一段再第二段
对平校验
回写后校验：方案待核销 = 需核销 − 已核销；不平则回滚并告警
